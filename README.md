
# Movie Recommendation Analysis

## Project Overview
This project analyzes movie datasets and recommends movies based on user ratings and genres.

## Technologies Used
- Python
- SQL
- Pandas
- NumPy
- Power BI
- Excel

## Features
- Data Cleaning
- SQL Analysis
   Recommendation System
- Interactive Dashboard

## Run Project
1. Install required libraries
2. Run clean_data.py
3. Run main.py
4. Open Power BI dashboard
